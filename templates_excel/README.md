# Plantillas Excel locales

Los archivos `.xlsx` de esta carpeta están excluidos de Git mediante `.gitignore` porque pueden contener información personal, salarial o bancaria.

Para ejecutar el proyecto localmente deben existir con estos nombres:

- `2026_CALCULO_DE_NOMINA.xlsx`
- `FORMATO_NOMINA_FIRMA.xlsx`
- `PLANTILLA_BANCO_PAGOS_NOMINA.xlsx`

No subir plantillas reales ni archivos de nómina al repositorio. En una etapa posterior se deben usar plantillas sanitizadas para desarrollo y Cloud Storage/gestión segura para archivos productivos.
