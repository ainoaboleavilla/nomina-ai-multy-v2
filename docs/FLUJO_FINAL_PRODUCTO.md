# Flujo final del producto

```text
NOVEDADES
   ↓
Excel / Formulario / IA
   ↓
EMPLEADOS
   ↓
¿Empleado nuevo?
   ├─ no → continuar
   └─ sí → completar datos → validar/sincronizar tercero Siigo
   ↓
MOTOR PYTHON DE NÓMINA
   ↓
Cálculo + Firma + Banco
   ↓
Panel por empleado / Panel por nómina
   ↓
REVISIÓN HUMANA
   ↓
APROBACIÓN
   ├─ Banco
   ├─ Comprobante contable Siigo
   └─ Nómina Electrónica mensual
         ↓
      Validación + JSON/CSV + auditoría
         ↓
      Adaptador oficial de transmisión
```

La facturación electrónica no forma parte del producto.
